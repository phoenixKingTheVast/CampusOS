Read them in this order:

1. `01-PART-I-II-FOUNDATION-AUTH-ONBOARDING.md`
2. `02-PART-III-IV-V-HOME-SEARCH-LEARN.md`
3. `03-PART-VI-VII-COURSE-ANNOUNCEMENTS-RESOURCES.md`
4. Then `../CAMPUSOS_ANDROID_AGENT_SPEC.md` and `../api-source-of-truth/` for the implemented API, remaining screens, architecture freeze, and Android-specific overrides. `services/api` is not required.
